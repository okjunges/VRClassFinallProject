# 서론 및 개요

한성대학교의 2025-2 가상현실 8 Final Project를 위해 개발된 게임 프로젝트. K-드라마, 영화, e-Sports 등 다양한 분야의 K-콘텐츠가 유행한다. 그 주역중 하나인 '오징어게임'에도 등장했던 숨바꼭질을 Unity로 구현해 다양한 이들이 즐길 수 있기를 바라며 본 프로젝트를 기획하였다.

장르: 3D 1인칭 싱글 플레이어 퍼즐 서바이벌 게임 몰입감있는 1인칭 시점으로 AI 추적자가 볼 수 없는 안전한 위치를 찾아 숨어야하는 서바이벌 3D 게임. 플레이어는 맵 상에 배치된 문을 조작하여 맵의 구조를 변경, 추적자가 찾기 어렵도록 장애물로써 사용한다.

## 핵심 목표

1. NavMeshAgent를 이용한 추적자 AI  
2. 플레이어의 의도에 따라 동적으로 변화하는 맵

## 개발 환경

- Unity 2022.3.42f1  
- Windows 11 Pro / MacOS

# 구현 세부

## 게임 흐름

1. 설정 및 설명이 포함된 메인 화면.  
2. 게임 시작 시 플레이어의 턴이 시작되며 주어진 시간 내에 문을 열고 닫으며 맵 안에서 안전한 곳을 찾아야한다.  
3. 주어진 시간이 모두 지나면 플레이어의 위치는 고정되고 술래의 턴으로 전환되며 시점도 동시에 술래에게 이동한다. 술래는 주어진 시간동안 맵을 자유롭게 탐색하며 플레이어를 찾는다.  
4. 플레이어가 술래에게 들키지 않고 같은 방식으로 5라운드를 이긴다면 최종 승리. 그렇지 않고 중간에 들키게 된다면 최종 패배하게 된다.

`Assets\stray\Scripts\PlayerControl.cs`   
플레이어 행동 정의

- WASD를 이용한 이동.  
- 마우스를 사용한 1인칭 시야 이동.  
- 교차점 근처에서 E를 사용해 상호작용.

### 추적자

`Assets\Scripts\Monster\MonsterLogic.cs`   
추격자 주요 행동 정의

- 단순히 미로 안을 랜덤하게 이동하며 플레이어를 찾는다.  
- 길 막힘 처리  
  2. 이동 중 벽에 막히면 새로운 경로를 탐색하여 이동한다.  
- 탐색 판정  
  2. 카메라의 시야각(FOV)에 기반한 View Frustum 확인.  
  3. 카메라 farClipPlane을 이용한 시야 거리 확인.  
  4. Raycast를 활용한 Line-of-Sight 가림체 체크를 조합해 몬스터가 플레이어를 실제로 ‘볼 수 있는지’를 판단하는 시각 기반 탐지 로직으로 플레이어를 발견했는지 판정.  
- 랜덤한 간격으로 좌/우를 살피고, 턴이 종료될 때 주변(좌우)을 살펴보는 모션.

`Assets\Scripts\Monster\MonsterVision.cs`   
추격자 시야 처리

- 술래의 카메라 기준으로 다음 조건을 모두 만족하면 플레이어 발견:  
  1. 60° 시야각(FOV) 내에 있음   
  2. 시야 거리(viewDistance) 내에 있음  
  3. 가시선(Line of Sight)에 장애물이 없음  
     (벽으로 가려지면 실패 \- Layout이 Wall이면 실패)

## 맵 상세

게임에 사용되는 맵은 프리팹화 되어 `Assets\Prefabs\Maps`에 저장되어있다.

맵의 경우, 이번 프로젝트에서 유니티 패키지인 2D 타일맵을 사용해 작성하였으나 그보다는 디자인에 중점을 두어 연구했다. 기본 콘셉트인 숨바꼭질과 문을 이용해 퍼즐을 작성하기 위해 몇가지 제약을 설정했다.

1. 플레이어와 술래의 경로가 완전히 막혀서는 안 될 것.  
2. 플레이어에게 안전한 장소인듯 속여 술래가 닿기 쉬운 막다른 길로 유도할 것.  
3. 플레이어가 긴장감을 느낄 수 있도록 아슬아슬한 상황을 유도할 것.

위 세가지 조건을 가능한 지키며 디자인하였다. 3번 맵을 예시로 들면, 문(교차점)은 숨는 위치를 탐색하기위한 지름길과 술래의 경로를 방해하기 위해서만 사용될 수 있고 맵 상의 모든 위치는 접근이 원천적으로 차단될 수 없다.
